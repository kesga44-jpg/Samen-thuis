# Samen Thuis

Een gezamenlijke thuisapp voor Kees en Daphne, geschikt voor iPad en laptop.

## Functies

- gezamenlijke planning;
- weekmenu;
- boodschappenlijst;
- huishoudtaken;
- voorraadbeheer;
- ideeën om samen te doen;
- woningbeheer;
- reisplanning;
- lokale opslag;
- JSON-back-up voor laptop of iCloud Drive;
- installatie als webapp op het iPad-beginscherm.

## Lokaal openen

Open `index.html` in een browser. Voor offline installatie en de service worker
moet de map via een eenvoudige lokale webserver of hostingdienst worden geopend.

## Op GitHub zetten zonder terminal

1. Maak op GitHub een nieuwe repository met de naam `samen-thuis`.
2. Zet de repository op **Private**.
3. Kies **Add file** en daarna **Upload files**.
4. Upload alle uitgepakte bestanden uit deze map.
5. Kies **Commit changes**.

De repository bevat alleen de broncode en voorbeeldgegevens. Gegevens die later
in de app op de iPad worden ingevoerd, worden lokaal bewaard en komen niet
automatisch in GitHub terecht.

## Back-up

Gebruik in de app de knop **Opslaan voor laptop**. Op een iPad kun je het
JSON-bestand via **Bewaar in Bestanden** in iCloud Drive plaatsen. Met
**Back-up laden** kunnen de gegevens later worden hersteld.
