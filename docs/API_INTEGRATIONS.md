# API- en externedienstenregister Samen Thuis

**Peildatum:** 2026-11-10 · **Codebasis:** `main` op `2348349` plus deze PR · **Productie/live:** niet bevestigd.

Dit register volgt de productie-entrypoint `index.html`; een URL in een CSP-voorstel, `sources.js`, test of Edge Function alleen telt niet als productie-integratie. In deze sessie konden externe API-hosts niet worden bereikt: zowel `curl` als Chromium faalden al bij DNS-resolutie. "Getest" hieronder betekent daarom een lokale test met nagebootste antwoorden, tenzij uitdrukkelijk anders vermeld. Geen enkele externe API wordt als live werkend aangemerkt.

## Statusbegrippen

- **Actief:** geladen productiecode roept de dienst aan.
- **Voorwaardelijk actief:** productiecode roept de dienst alleen na een gebruikersactie of onder een voorwaarde aan.
- **Bèta / voorbereid:** code bestaat, maar wordt niet geladen of aangeroepen door `index.html`.
- **Ongebruikt:** geen productie-aanroep; alleen losse code, documentatie of een verwijzing.
- **Verwijderd:** de productie-integratie is doelbewust weggehaald.

### BrainyQuote: herkomst, gedrag en activeringspunt

De oude `<script src="https://www.brainyquote.com/link/quotebr.js">`-integratie is verwijderd in [`patches/PR-2-2-r4-brainyquote.patch`](../patches/PR-2-2-r4-brainyquote.patch): code van een derde draaide in dezelfde pagina als ontsleutelde gegevens en tokens. De patch verving de kaart door eigen lokale gedachten, maar liet een losse RSS-refresh over. Die RSS-functie was al aan de app-start gekoppeld; er ontbraken echte feedtests, een dagelijkse pogingregistratie bij fouten en veilige rendering van gecachte markup.

Deze wijziging behoudt de oorspronkelijke officiële feed (`https://www.brainyquote.com/link/quotebr.rss`), maar herstelt verwerking als onbetrouwbare tekst. De UI gebruikt nooit externe HTML, toont BrainyQuote als bron, bewaart de laatste geldige quote en toont die ook wanneer verouderd/offline. Een mislukte poging telt die kalenderdag mee, zodat paginawissels of herladen geen fetchlus veroorzaken. Als directe browsertoegang door CORS/netwerk faalt, kan de reeds bestaande JWT-beveiligde `data-sources` Edge Function de feed ophalen. **Die nieuwe Edge-actie moet na review door de eigenaar worden gedeployed; er is hier geen productie-Supabase-wijziging uitgevoerd.** Zonder die deployment blijft de directe route bruikbaar waar CORS dit toestaat en anders de lokale/laatst bekende fallback.

De feed wordt in deze omgeving niet live bereikt; CORS-ondersteuning is dus onbekend. BrainyQuote documenteert de RSS-bron op [BrainyQuote Feeds](https://www.brainyquote.com/feeds), maar live browsergedrag moet na netwerktoegang en Edge-deployment worden gecontroleerd. De oude uitvoerbare scriptintegratie blijft verwijderd.

- **BrainyQuote JavaScript-feed `quotebr.js`: verwijderd**; niet opnieuw laden vanwege R4 (derde-partijcode op een pagina met ontsleutelde gegevens). De RSS-feed is een andere, tekstuele integratie.

## CSP, service worker en verificatie

- `index.html` heeft geen actieve CSP-meta-policy; het CSP-blok in `docs/SECURITY.md` is een voorstel, geen productiebeveiligingsgrens. Deze wijziging voegt geen host toe aan een niet-bestaande actieve policy.
- `sw.js` precachet lokale app-assets en geeft externe requests door aan het netwerk; RSS wordt niet door de service worker gecachet. De aparte localStorage-quote-cache verzorgt offline gebruik.
- Nieuwe en bestaande lokale tests: `brainyquote-rss-core.test.js`, `quotes-core.test.js`, `e2e/smoke.mjs`, `sw-assets.test.js`, `edge-guard.test.js` en de volledige `node --test *.test.js` suite.
- Live status moet apart worden ingevuld na toegang tot DNS/netwerk en, voor de serverfallback, na goedgekeurde deployment van `data-sources`. Mocktests zijn geen live API-test.
